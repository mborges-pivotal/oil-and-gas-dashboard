# Oil and Gas Dashboard
The goal is to bring relevant information about the industry and key players into a single dashboard.

## Initial Prompt Used
I would like to build a single page web app that would allow me to see Oil prices from the common indexes and 
select indexes to see the spread, in particular, Brent vs WTI. I would like to be able to see US national gas 
prices and the calculated crack spread. Then I would like another view for selected Oil & Gas public companies 
based on the configuraiton of the stock ticker. And a news agregatore based on RSS and finally the ability to 
collect the following informaiton from the public companies: annual report, 10k, earnings call / transcript and 
financial news or website RSS information
